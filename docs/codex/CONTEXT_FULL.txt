lifecycle/matching -> positions/accounting/PnL -> recovery/reconciliation.

manual_trading.h. Market state, strategy signal orchestration, portfolio/manual

LIVE SERVICE ORDERING
=====================
Market SQLite commit -> MarketDataUpdated -> StrategyIntentBatch.
PortfolioRisk joins intent(T) with AccountSnapshot(T), reads bounded history,
and emits DecisionBatch. ExecutionState selects exact close(T) and requests a
NotionalOrderPlan. The planner returns USD intent. The current default LIVE
deployment stops at that pre-exchange boundary: ExecutionState does not submit
exchange orders. Other execution/runtime components support durable order state
and gateway handoff; do not describe that capability as connected LIVE routing. Inspect deploy/live configuration rather than assuming
private routing is active. execution_service is an alternative direct route.

Durability order is service-specific:
- ingestion: SQLite COMMIT, then update notification;
- strategy/risk/planner: deterministic output publish, checkpoint, input ACK;
- execution: persist local order/cancel intent before outbound commands;
- simulated backend with persistence: account/order state plus durable outbox
  in one transaction, then publish the outbox.
Preserve these crash contracts, IDs, ordering and duplicate handling.
Business time comes from TimeHandler; technical polling/backoff uses real time.
Shared ClockState/replay-controller infrastructure has been removed.
